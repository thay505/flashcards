# Flashcards Azul - versão simples

Projeto escolar de flashcards feito com HTML, CSS e JavaScript.

## Arquivos

- index.html
- estilos.css
- script.js

## Como usar

Abra a pasta no VS Code e execute o arquivo `index.html`.

Você também pode usar a extensão Live Server.

## Como trocar as perguntas

Abra o `script.js` e edite a lista `flashcards`.
